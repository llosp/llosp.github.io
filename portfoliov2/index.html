02

About

I'm a game designer with a systems brain — happiest somewhere between a design doc, a spreadsheet and an engine.

Design student at PUC-Rio. At Prisma Game Lab I've worked both as a game designer and coordinating project teams — shipping prototypes, running playtests and keeping design and implementation talking to each other.

I'm a generalist by choice: I prototype in Unity and Godot, write gameplay code, make 2D art and 3D models, design UI — and I keep every system honest with attribute tables, progression curves and balancing sheets.
